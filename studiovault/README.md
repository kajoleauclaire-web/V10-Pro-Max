# StudioVault

গেম স্টুডিওদের কোড ও ডেভেলপমেন্ট রেকর্ড AI ল্যাবের কাছে লাইসেন্স করার মার্কেটপ্লেস।
A marketplace where game studios license their code and development records to AI labs.

## কী কী আছে / What it does

| কার জন্য | কী করতে পারে |
| --- | --- |
| **ভিজিটর** | ল্যান্ডিং পেজে কয়েকটা প্রশ্নের উত্তর দিয়ে তাদের কোডের আনুমানিক লাইসেন্স মূল্য দেখে। ইমেইল দিলে সেটা আপনার কাছে "lead" হিসেবে জমা হয়। |
| **গেম স্টুডিও** | অ্যাকাউন্ট খোলে, ডেটাসেট লিস্ট করে, দাম চায়, অফার গ্রহণ বা প্রত্যাখ্যান করে, ডিল ও নিজের পাওনা দেখে। |
| **AI ল্যাব (ক্রেতা)** | অনুমোদিত লিস্টিংয়ের ক্যাটালগ খোঁজে, অফার পাঠায়, নিজের অফার ও ডিল দেখে। |
| **অ্যাডমিন (আপনি)** | প্রতিটি লিস্টিং অনুমোদন/বাতিল করেন, lead, ডিল, মোট লেনদেন ও আপনার কমিশন দেখেন, ডিলের অবস্থা আপডেট করেন। |

স্টুডিও অফার গ্রহণ করলে একটা ডিল তৈরি হয় এবং আপনার কমিশন (ডিফল্ট ১৫%) স্বয়ংক্রিয়ভাবে হিসাব হয়।

## চালানো / Run

Node.js 22.13 বা নতুন লাগবে। কোনো প্যাকেজ ইনস্টল করতে হয় না।

```bash
cd studiovault
ADMIN_EMAIL=you@example.com ADMIN_PASSWORD='a-long-password' npm start
```

তারপর ব্রাউজারে `http://localhost:3000` খুলুন। `ADMIN_PASSWORD` না দিলে প্রথমবার চালুর সময় একটা র‍্যান্ডম পাসওয়ার্ড টার্মিনালে একবারই দেখানো হয়।

ডেমো ডেটা দিয়ে দেখতে চাইলে (শুধু নিজের কম্পিউটারে, লাইভ সাইটে কখনো নয়):

```bash
npm run seed   # admin@demo.test, studio@demo.test, buyer@demo.test — password: demo-password
npm start
```

টেস্ট: `npm test`

## সেটিংস / Settings (environment variables)

| নাম | ডিফল্ট | কাজ |
| --- | --- | --- |
| `PORT` | `3000` | সার্ভারের পোর্ট |
| `DB_PATH` | `data/studiovault.db` | SQLite ডেটাবেস ফাইল (এটার ব্যাকআপ রাখুন) |
| `FEE_RATE` | `0.15` | প্রতি ডিলে আপনার কমিশন |
| `ADMIN_EMAIL`, `ADMIN_PASSWORD` | — | প্রথম অ্যাডমিন অ্যাকাউন্ট |
| `COOKIE_SECURE` | — | HTTPS-এ চালালে `1` দিন |
| `TRUST_PROXY` | — | Nginx/হোস্টিং প্রক্সির পেছনে থাকলে `1` দিন |

দাম অনুমানের সব রেট `src/valuation.js`-এর `RATES`-এ এক জায়গায় আছে; আসল ডিল থেকে শিখে সেগুলো বদলান।
ব্র্যান্ড নাম বদলাতে `public/index.html` ও `public/app.js`-এ "StudioVault" খুঁজে বদলান।
